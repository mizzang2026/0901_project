# 개인 프로필 페이지 문서

HTML, CSS, JavaScript만 사용해 반응형 개인 프로필 페이지를 제작하기 위한 문서입니다.

## 문서 목록

- [요구사항 명세](./requirements.md): 페이지 목적, 콘텐츠, 기능, 품질 기준
- [화면 및 디자인 설계](./design.md): 레이아웃, 색상, 반응형 동작
- [구현 가이드](./implementation.md): 파일 구조, 구현 순서, 점검 항목

## 프로젝트 목표

- 방문자가 프로필 주인에 대한 핵심 정보를 빠르게 이해할 수 있게 한다.
- 기술, 프로젝트, 경력, 연락 방법을 한 페이지에서 확인할 수 있게 한다.
- 모바일과 데스크톱에서 모두 편하게 사용할 수 있게 한다.
- 프레임워크 없이 표준 HTML, CSS, JavaScript로 구현한다.

## 권장 결과물

```text
frontend/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  └─ main.js
└─ assets/
   ├─ images/
   └─ icons/
```

개인 정보와 이미지가 준비되지 않은 경우에는 임시 콘텐츠를 넣고, 실제 배포 전에 교체합니다.
