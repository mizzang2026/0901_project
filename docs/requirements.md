# 요구사항 명세

## 1. 페이지 목적

개인의 소개, 보유 기술, 대표 프로젝트와 연락처를 보여주는 단일 페이지 프로필 사이트를 만든다.

## 2. 대상 사용자

- 채용 담당자 및 협업 파트너
- 프로젝트와 기술 역량에 관심 있는 방문자
- 연락처와 소셜 링크를 찾는 방문자

## 3. 페이지 구성

### 헤더와 내비게이션

- 이름 또는 로고를 표시한다.
- 소개, 기술, 프로젝트, 연락처 섹션으로 이동하는 메뉴를 제공한다.
- 모바일에서는 메뉴 버튼으로 내비게이션을 열고 닫을 수 있게 한다.

### 소개 영역

- 프로필 이미지, 이름, 직무 또는 한 줄 소개를 표시한다.
- 2~4문장 분량의 자기소개를 제공한다.
- 프로젝트 보기와 연락하기 버튼을 제공한다.

### 기술 영역

- HTML, CSS, JavaScript 등 보유 기술을 카드나 태그 형태로 표시한다.
- 필요하면 기술별 숙련도 또는 경험 내용을 짧게 덧붙인다.

### 프로젝트 영역

프로젝트마다 다음 정보를 제공한다.

- 프로젝트 이미지 또는 미리보기
- 프로젝트명과 간단한 설명
- 사용 기술
- 데모 및 저장소 링크

최소 2개 이상의 프로젝트를 표시하는 것을 권장한다.

### 경력 또는 활동 영역

- 경력, 학력, 자격, 교육 또는 주요 활동을 시간순으로 표시한다.
- 관련 내용이 없다면 이 영역은 생략할 수 있다.

### 연락처 영역

- 이메일, GitHub, 블로그 또는 소셜 링크를 제공한다.
- 연락 폼을 사용할 경우 이름, 이메일, 메시지 필드를 포함한다.
- 별도 백엔드가 없다면 폼은 실제 전송 대신 이메일 링크 또는 전송 안내를 사용한다.

### 푸터

- 저작권 문구와 주요 소셜 링크를 표시한다.
- 연도는 JavaScript로 현재 연도를 자동 표시할 수 있다.

## 4. JavaScript 기능

필수 기능:

- 모바일 내비게이션 열기 및 닫기
- 메뉴 클릭 시 해당 섹션으로 부드럽게 이동
- 푸터의 현재 연도 자동 표시

선택 기능:

- 라이트/다크 테마 전환 및 선택값 저장
- 스크롤 위치에 따른 현재 메뉴 강조
- 프로젝트 목록 필터링
- 화면 진입 시 가벼운 요소 애니메이션
- 연락 폼 입력값 검증

## 5. 비기능 요구사항

- 모바일 우선으로 작성하고 주요 화면 크기에서 레이아웃이 깨지지 않아야 한다.
- 시맨틱 HTML 요소를 사용한다.
- 키보드만으로 메뉴와 링크, 버튼을 조작할 수 있어야 한다.
- 이미지에는 의미 있는 `alt` 텍스트를 제공한다.
- 텍스트와 배경의 명암 대비를 충분히 확보한다.
- 애니메이션은 과도하지 않게 사용하며 모션 감소 설정을 존중한다.
- 외부 링크에는 안전한 속성을 적용한다.
- 이미지 크기를 최적화하고 불필요한 라이브러리는 사용하지 않는다.

## 6. 준비할 콘텐츠

- 이름과 직무명
- 한 줄 소개와 상세 자기소개
- 프로필 사진
- 보유 기술 목록
- 프로젝트별 제목, 설명, 이미지, 기술, 링크
- 경력 또는 활동 이력
- 공개 가능한 이메일 및 소셜 링크
- 이력서 파일 또는 링크(선택)
