# 화면 및 디자인 설계

## 1. 전체 레이아웃

```text
┌──────────────────────────────────┐
│ 로고/이름              내비게이션 │
├──────────────────────────────────┤
│ 프로필 이미지     이름/소개/버튼 │
├──────────────────────────────────┤
│ 기술 카드 또는 기술 태그          │
├──────────────────────────────────┤
│ 프로젝트 카드 목록                │
├──────────────────────────────────┤
│ 경력/활동 타임라인                │
├──────────────────────────────────┤
│ 연락처 및 소셜 링크               │
├──────────────────────────────────┤
│ 푸터                              │
└──────────────────────────────────┘
```

## 2. 디자인 방향

- 분위기: 단정하고 현대적인 포트폴리오
- 콘텐츠 최대 너비: 약 `1120px`
- 본문 좌우 여백: 모바일 `20px`, 태블릿 이상 `32px`
- 섹션 상하 간격: 모바일 `64px`, 데스크톱 `96px`
- 카드 모서리: `12px`~`16px`
- 그림자는 약하게 적용하고 강조색은 버튼과 링크에 집중한다.

## 3. 색상 변수 예시

```css
:root {
  --color-bg: #f8fafc;
  --color-surface: #ffffff;
  --color-text: #0f172a;
  --color-muted: #64748b;
  --color-primary: #2563eb;
  --color-primary-hover: #1d4ed8;
  --color-border: #e2e8f0;
}
```

색상은 CSS 변수로 관리해 일관성을 유지하고 테마 변경이 쉽도록 한다.

## 4. 타이포그래피

- 기본 글꼴은 시스템 글꼴 또는 한글 웹 폰트를 사용한다.
- 본문 기본 크기는 `16px`, 줄 높이는 `1.6` 이상을 권장한다.
- 제목 단계(`h1`~`h3`)가 시각적으로 명확히 구분되어야 한다.
- 긴 문단의 가로 폭은 읽기 편하도록 제한한다.

## 5. 반응형 기준

- 모바일: `0px`~`767px`
- 태블릿: `768px`~`1023px`
- 데스크톱: `1024px` 이상

모바일에서는 소개와 프로젝트 카드를 한 열로 배치한다. 넓은 화면에서는 소개 영역을 두 열로, 프로젝트 카드를 2~3열로 배치한다.

## 6. 인터랙션 기준

- 버튼과 링크는 hover뿐 아니라 focus 상태도 제공한다.
- 모바일 메뉴 버튼에는 현재 열림 상태를 `aria-expanded`로 표시한다.
- 애니메이션 시간은 보통 `150ms`~`300ms`로 유지한다.
- `prefers-reduced-motion` 환경에서는 부드러운 스크롤과 진입 애니메이션을 줄이거나 제거한다.
