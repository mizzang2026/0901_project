LEARNING LOG · DAY 07 · 2026.09.21

로그인과 게시판을
실제 정보로 바꾸기

화면에 미리 적어 둔 예시 내용을 지우고, 로그인한 사람의 정보와 직접 작성한 게시글이 보이도록 바꿉니다. 관리자 계정도 따로 만들 수 있게 정리합니다.

로그인데이터베이스게시판관리자
01

로그인한 사람의 정보 보여주기

지금 프로필 페이지에는 이름과 이메일이 미리 적혀 있습니다. 이 내용을 지우고, 실제로 로그인한 사람의 이름과 이메일이 나타나도록 바꿉니다.

회원가입→정보 저장→로그인→내 정보 표시

회원 정보 저장

회원가입할 때 입력한 내용을 데이터베이스에 저장합니다.

내 정보 표시

로그인하면 저장된 내 이름과 이메일을 불러와 보여줍니다.

쉽게 말하면, 누구에게나 똑같은 예시 프로필을 보여주는 것이 아니라 로그인한 사람마다 자신의 정보가 보이게 만드는 작업입니다.

02

메뉴에서 프로필 버튼 삭제

위쪽 메뉴를 확인하고 프로필 페이지로 이동하는 버튼을 삭제합니다. 컴퓨터 화면과 모바일 화면에서도 버튼이 남아 있지 않은지 함께 확인합니다.

메뉴 확인전체 메뉴에 어떤 버튼이 있는지 확인
버튼 삭제메뉴에 있는 프로필 버튼 제거
화면 확인컴퓨터와 모바일 화면에서 다시 확인
03

게시판이 실제로 동작하게 만들기

게시판에 미리 적어 둔 예시 글을 모두 지웁니다. 내가 작성한 글은 데이터베이스에 저장하고, 저장된 글은 게시판 목록과 상세 페이지에서 볼 수 있게 만듭니다.

글 작성→글 저장→목록에 표시→내용 확인

글 보기

저장된 글을 게시판 목록과 상세 페이지에서 보여줍니다.

글 관리

내가 쓴 글을 수정하거나 삭제할 수 있게 만듭니다.

게시판에 미리 넣어 둔 예시 글을 모두 지워줘.
내가 작성한 글은 데이터베이스에 저장하고,
게시판에서 다시 볼 수 있게 만들어줘.

“하드코딩된 부분을 제거해 줘”라고 말해도 뜻은 전달됩니다. 여기에 “데이터베이스에 저장해 줘”라고 덧붙이면 원하는 작업을 더 쉽게 설명할 수 있습니다.

04

관리자 계정 따로 만들기

관리자는 일반 회원가입으로 만들지 않습니다. .env 파일에 내가 사용할 관리자 이메일과 비밀번호를 적으면, 그 정보로 관리자 계정을 만들도록 합니다.

# 실제 값은 직접 입력하고 Git에 올리지 않습니다.
ADMIN_EMAIL=내가_사용할_관리자_이메일
ADMIN_INITIAL_PASSWORD=내가_정한_초기_비밀번호
관리자 정보 입력→계정 확인→안전하게 저장→관리자 로그인

관리자가 없는 경우

.env에 입력한 정보로 새 관리자 계정을 만듭니다.

정보가 다른 경우

입력한 정보가 맞는지 확인하고 관리자 계정 정보를 다시 설정합니다.

비밀번호를 안전하게 바꾸어 저장하는 과정은 프로그램이 알아서 처리합니다. .env 파일은 중요한 정보가 들어 있으므로 GitHub에는 올리지 않습니다.

05

관리자가 게시글 관리하기

실제로 사이트를 만들 때는 Next.js를 이용할 수도 있습니다. 일반 사용자 화면과 관리자 화면을 나누어 만들고, 관리자 로그인도 일반 로그인과 따로 구분하는 방법을 배웠습니다.

관리자 로그인→게시글 확인→삭제·숨김→화면에 반영

게시글 삭제

관리자가 문제가 있는 게시글을 확인하고 삭제할 수 있게 합니다.

게시글 숨김

글을 바로 삭제하지 않고 사용자 화면에서 보이지 않게 숨길 수도 있습니다.

게시글을 삭제하거나 숨기면 그 결과를 데이터베이스에 저장합니다. 따라서 페이지를 새로 열어도 변경된 상태가 그대로 유지됩니다.

관리자가 로그인하면 모든 사용자의 게시글을 확인하고,
필요한 글을 삭제하거나 숨길 수 있게 만들어줘.
변경한 내용은 데이터베이스에 저장해줘.

관리자 기능은 일반 사용자가 이용할 수 없도록 관리자 계정으로 로그인했을 때만 보여줍니다.
