배포된 서비스의 사용자 기능 점검하기

Vercel과 Supabase 화면을 함께 열고 가입 → 로그인 → 글 → 댓글 → 반응 순서로 실제 작동 여부를 확인했습니다.

1. 준비 2. 사용자 기능 점검 3. 관리자 기능 4. 다음 시간 5. 기억할 순서

1. 작업 전 준비

Vercel, Supabase, 실제 인터넷 페이지를 모두 열어 놓고 작업을 시작합니다.

화면확인하는 내용
인터넷 페이지사용자에게 보이는 화면과 버튼의 실제 동작
Supabase사용자와 게시글·댓글 데이터가 실제로 저장되는지
Vercel최신 배포 상태와 오류 로그, 환경 변수

2. 사용자 기능 점검 순서

  1. 회원 생성 확인 — 회원가입 후 Supabase 사용자 목록에 새 사용자가 추가됐는지 확인한다.
  2. 로그인·회원가입 — 메인 화면에서 두 기능이 정상적으로 동작하는지 확인한다.
  3. 프로필 전환 — 로그인 후 프로필 버튼을 눌렀을 때 내 프로필 화면으로 이동하는지 확인한다.
  4. 게시글 작성 — 로그인한 사용자가 게시글을 작성하고 저장할 수 있는지 확인한다.
  5. 다른 사용자 댓글 — 다른 계정으로 로그인해 작성된 게시글에 댓글을 남길 수 있는지 확인한다.
  6. 게시글 반응 — 조회수, 좋아요, 싫어요가 각각 정상적으로 작동하는지 확인한다.

중요: 화면에서 버튼이 눌리는 것만 보지 않고, Supabase에서 해당 데이터가 실제로 생성되거나 변경됐는지도 함께 확인합니다.

4. 관리자 페이지에서 필요한 기능

  • 신고 관리 — 접수된 신고 확인과 처리
  • 백업 — 데이터 보관과 복구 준비
  • 공지사항 — 공지 작성과 관리
  • 이용약관 — 서비스 약관 관리
  • 개인정보처리방침 — 개인정보 안내 관리
  • 1:1 문의 — 사용자 문의 확인과 답변

5. 다음 시간에 할 일

  1. 관리자 페이지 매칭 — 실제 데이터와 관리자 화면을 연결한다.
  2. 운영 기능 — 공지사항, 1:1 문의, 신고 기능을 만든다.
  3. 푸터 정보 — 개인정보처리방침과 이용약관 링크를 추가한다.
  4. 소셜 로그인 — 카카오 로그인 추가를 검토한다.
  5. 결제와 확장 기능 — 토스페이먼츠 결제 모듈, 뉴스레터 등의 필요성을 검토한다.
  6. 정식 공개 준비 — 도메인 구매·연결, SEO, 서비스 주소 매칭을 진행한다.

오늘의 핵심 순서

한 기능씩 계정을 바꿔 가며 실제 사용자 흐름 전체를 시험합니다.
