LEARNING LOG · DAY 02

AI로 개인 프로필
웹페이지 만들기

AI의 도움을 받아 나만의 개인 프로필 웹페이지를 직접 기획하고, 만들고, 반복해서 개선한 과정을 기록했습니다.

01

개인 프로필 페이지 만들기

개인 프로필 페이지에 어떤 내용을 담을지 구성하고, AI에게 원하는 페이지의 형태를 설명하여 실제 웹페이지로 만들어 보았습니다.

단순히 코드를 직접 작성하는 것뿐 아니라 다음 세 가지를 AI에게 구체적으로 설명하는 것이 중요하다는 것을 알게 되었습니다.

어떤 페이지를
만들고 싶은지→ 어떤 내용이
들어가야 하는지→ 어떤 분위기로
보여주고 싶은지
02

프로필 내용 구성하기

개인 프로필 페이지에는 나를 소개하는 다양한 정보를 섹션별로 구성할 수 있습니다.

Profile이름과 한 줄 소개
About Me나에 대한 간단한 소개
Interests관심 분야
Currently Learning현재 배우고 있는 것
Projects앞으로 만들 프로젝트
My Journey학습 과정과 경험
Tools I'm Learning현재 배우고 사용하는 도구

처음부터 모든 내용을 완성할 필요는 없습니다. 배우고 경험하는 것이 늘어날 때마다 추가하며 계속 발전시키는 개인 페이지로 만들 수 있습니다.

03

AI에게 수정 요청하기

처음 만들어진 결과물을 그대로 사용하는 것이 아니라 원하는 방향으로 계속 수정할 수 있습니다.

  • 글자의 크기나 위치 변경
  • 배경이나 전체적인 분위기 변경
  • 새로운 메뉴나 영역 추가
  • 필요 없는 부분 삭제
  • 문구 수정
  • 모바일 화면에 맞게 조정

AI 코딩에서는 코드를 모두 직접 작성하는 것뿐 아니라 원하는 결과를 명확하게 설명하고 수정 요청을 반복하는 과정도 중요합니다.

04

AI로 프로필 이미지 만들기

웹페이지에 사용할 프로필 이미지도 AI를 이용해 직접 제작해 보았습니다.

단순히 “개발자 이미지 만들어줘”라고 요청하기보다 다음 조건을 구체적으로 설명하는 것이 좋습니다.

인물의 분위기+그림 스타일+직업적인 느낌+사용 목적

“소녀 감성보다는 커리어 우먼 느낌으로”

“사진보다는 일러스트 느낌으로”

“너무 예쁘게 표현하지 말고 자연스럽게”

AI 이미지 생성도 한 번의 명령으로 끝나는 것이 아니라, 결과를 보고 프롬프트를 구체화하며 원하는 모습에 가까워지는 과정입니다.

05

생성한 이미지를 웹페이지에 사용하기

AI로 생성한 이미지를 파일로 준비한 뒤 웹 프로젝트의 적절한 폴더에 넣고, 코드에서 해당 이미지 파일을 불러와 화면에 표시합니다.

frontend/
└─ assets/
   └─ images/
      └─ profile.png

프로필 사진은 페이지 디자인에 따라 원형이나 사각형으로 표현할 수 있고, 이미지 크기와 배치도 CSS로 조절할 수 있습니다.
