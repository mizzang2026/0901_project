GitHub Pages와 Google 스프레드시트를 열고 데이터 연동을 준비하면서, 기존 개인 프로필 사이트를 게시글 중심의 블로그 구조로 변경했습니다.

BlogGoogle SheetsDBCodex
01

Google Sheets를 DB처럼 사용하기

GitHub Pages는 정적 웹사이트이므로 자체적으로 데이터를 저장할 서버가 없습니다. 수업에서는 Google 스프레드시트를 간단한 데이터 저장소처럼 사용하고 Google Apps Script를 연결 통로로 활용할 예정입니다.

웹페이지 입력→Apps Script→Google Sheets 저장→웹페이지 조회
02

모델과 추론 수준

gpt-5.6-sol은 모델 이름이고, low와 medium은 답변 전에 추론에 들이는 노력 수준입니다. Low는 빠른 작업에, Medium은 더 복잡하고 꼼꼼한 판단에 적합합니다.

03

프로필 사이트를 블로그로 변경

홈 화면을 자기소개 중심에서 최근 게시글 중심으로 바꾸고, 기존 날짜별 페이지는 학습기록 하위 메뉴에 모았습니다.

블로그 홈

최근 글, 글 요약, 주제 태그를 먼저 보여줍니다.

학습기록 메뉴

0831, 0901, 0907, 0908 기록을 날짜순으로 찾을 수 있습니다.

04

블로그 기본 화면 추가

앞으로 데이터 연동에 사용할 회원가입, 로그인, 프로필, 게시글 목록, 게시글 상세, 게시글 작성 화면을 먼저 구성했습니다.

현재는 화면 구조를 만든 단계입니다. 실제 저장과 로그인 처리는 Google Sheets 및 Apps Script 연동 후 구현합니다.
