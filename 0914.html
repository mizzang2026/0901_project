로그인 상태에 따라 메뉴를 바꾸고, Google Sheets에 저장되는 게시글 CRUD를 구현했습니다. 프로필과 게시글 화면의 더미 데이터를 실제 API 데이터로 교체했습니다.

01

로그인 상태에 따른 메뉴 변경

브라우저의 localStorage에 로그인 토큰과 사용자 정보를 보관하고, 로그인 여부에 따라 상단 메뉴가 자동으로 바뀌도록 구현했습니다.

로그아웃 상태회원가입 · 로그인 메뉴 표시
로그인 상태프로필 · 로그아웃 · 글쓰기 메뉴 표시
로그아웃 처리브라우저의 토큰과 사용자 정보 삭제

토큰의 존재만 확인하는 것으로 끝내지 않고, 보호된 기능은 Apps Script에서도 세션 유효성과 사용자 권한을 다시 검사합니다.

02

Google Sheets 게시글 CRUD 구현

Apps Script에 Posts 시트 생성과 게시글 작성·목록·상세·수정·삭제 API를 추가했습니다. 작성된 글은 메인과 게시글 목록에 자동으로 표시됩니다.

내용 입력→유효성 검사→데이터 저장→목록·상세 반영

조회와 이동

카드에 게시글 ID를 연결해 목록에서 실제 상세 페이지로 이동합니다.

작성자 권한

로그인 사용자 ID와 게시글의 userId가 같을 때만 수정·삭제합니다.

CRUD는 생성(Create), 조회(Read), 수정(Update), 삭제(Delete)를 뜻합니다.

03

더미 데이터와 하드코딩 제거

프로필에 고정되어 있던 사용자명과 게시글 통계, 게시글 목록과 상세의 예시 데이터를 제거했습니다. 로그인 사용자와 Apps Script API 응답으로 화면을 구성합니다.

  1. 프로필 이름·이메일을 me API 결과로 표시합니다.
  2. 본인이 작성한 게시글 수와 목록을 실제 데이터로 계산합니다.
  3. 데이터가 없을 때 빈 상태 안내를 표시합니다.
  4. 날짜별 학습기록은 실제 콘텐츠이므로 유지합니다.

하드코딩을 없애면 데이터가 바뀔 때 HTML을 매번 수정하지 않아도 되고, 모든 사용자가 자신의 최신 정보를 볼 수 있습니다.

04

분류와 게시글 화면 개선

글쓰기 분류를 네 가지로 정리하고, 게시글 목록을 분류별 섹션으로 나눴습니다. 상세 화면에서는 작성자 정보를 가장 먼저 보여줍니다.

게시글 분류

AI 활용, Q & A, 입트영, 일 상으로 나눠 표시합니다.

상세 정보

작성자 → 분류 → 작성일 순서로 표시합니다.

화면 코드가 갱신될 때 브라우저가 오래된 JavaScript를 사용하지 않도록 스크립트 버전도 변경했습니다.

05

Codex가 멈춘 느낌일 때 확인하기

응답이 느리거나 이전 작업이 끊긴 것처럼 보이면 모델과 세션 상태를 먼저 확인하고, 저장된 작업 세션을 다시 이어갑니다.

/model현재 모델을 확인하거나 사용할 모델을 변경합니다.
/status현재 세션 설정과 컨텍스트·토큰 사용 상태를 확인합니다.
/resume저장된 이전 작업 세션을 찾아 이어서 진행할 때 기억할 명령입니다.
codex resume --last터미널에서 가장 최근 Codex 세션을 바로 이어갑니다.

기억해 둘 프롬프트

“왜 멈춘 것처럼 보이는지 상태를 확인하고, 하던 작업을 계속 진행해줘.”

“현재 모델과 세션 상태, 남은 컨텍스트를 확인해줘.”

“이전 작업 내용을 확인하고 완료되지 않은 부분부터 이어서 해줘.”

기억: 새 대화를 시작하기 전에는 /status로 상태를 확인하고, 기존 작업을 이어야 한다면 먼저 세션 재개를 시도합니다.
