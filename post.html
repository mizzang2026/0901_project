DB처럼 연결하기

정적 웹사이트에서도 Google Apps Script를 중간 연결 통로로 사용하면 스프레드시트에 데이터를 저장하고 불러올 수 있습니다.

현재 수업에서는 GitHub Pages로 연 웹사이트와 Google 스프레드시트를 함께 준비했습니다.

전체 연결 구조

사용자가 웹페이지의 입력 폼을 작성하면 JavaScript가 데이터를 Google Apps Script로 전송합니다. Apps Script는 전달받은 값을 스프레드시트의 새로운 행에 저장합니다.

다음 단계

스프레드시트의 열 구조를 정하고 Apps Script 웹 앱 주소를 발급한 뒤, 게시글 작성 폼과 연결할 예정입니다.

회원 비밀번호 같은 민감한 정보는 단순 스프레드시트에 그대로 저장하지 않습니다.
