LEARNING LOG · DAY 01

AI 웹 개발
학습 기록

개발 작업 공간부터 AI 코딩 에이전트까지, 웹 개발을 시작하기 위해 알아야 할 도구와 기술의 관계를 정리했습니다.

01

VS Code — 개발 작업 공간

VS Code(Visual Studio Code)는 코드를 작성하고 프로젝트 파일을 관리하는 개발 도구입니다.

쉽게 말하면 프로그램이나 웹사이트를 만드는 작업실이라고 생각하면 됩니다.

코드를 작성하는 것뿐 아니라 프로젝트 파일을 관리하고, 터미널을 열어 필요한 명령어를 실행할 수도 있습니다.

VS Code 공식 다운로드 ↗
02

Terminal — 명령어를 입력하는 공간

터미널(Terminal)은 컴퓨터에게 명령을 직접 입력하는 공간입니다. Windows에서는 대표적으로 CMD(Command Prompt)와 PowerShell을 사용할 수 있습니다.

VS Code에서 터미널을 열면 기본 설정에 따라 PowerShell이나 CMD가 실행됩니다.

  • Terminal명령어를 입력하는 공간
  • CMDWindows의 전통적인 명령 환경
  • PowerShellWindows의 좀 더 강력한 명령 환경

즉, VS Code 안에서도 CMD나 PowerShell을 이용해 명령을 실행할 수 있습니다.

03

HTML → JavaScript → React → Next.js

웹 개발 기술은 서로 따로 떨어져 있는 것이 아니라 연결되어 있습니다.

HTML웹페이지의 기본 구조
→
JavaScript웹페이지의 동작과 기능
→
React컴포넌트 단위의 화면 조립
→
Next.jsReact 기반 웹서비스 개발

HTML

글, 이미지, 버튼 등 화면에 무엇을 보여줄지 구성합니다.

JavaScript

버튼 클릭, 검색, 데이터 처리처럼 사용자의 행동에 반응하도록 만듭니다.

React

화면을 작은 컴포넌트로 만들고 조립하여 복잡한 화면을 효율적으로 관리합니다.

Next.js

React를 기반으로 실제 웹사이트와 웹서비스를 편리하게 만드는 프레임워크입니다.

04

Node.js — JavaScript 실행 환경

Node.js는 웹브라우저 밖에서도 JavaScript를 실행할 수 있게 해주는 프로그램입니다.

Node.js를 설치하면 패키지 관리 도구인 npm도 함께 설치됩니다. 따라서 npm이나 Codex CLI를 사용하려면 Node.js를 먼저 설치해야 합니다.

  1. Node.js 공식 다운로드 페이지를 엽니다.
  2. 안정적으로 오래 지원되는 LTS 버전을 선택해 설치 파일을 받습니다.
  3. 다운로드한 설치 파일을 실행하고 기본 설정으로 설치합니다.
  4. VS Code와 터미널을 다시 연 뒤 설치 여부를 확인합니다.
Node.js 공식 다운로드 ↗
node --version설치된 Node.js 버전을 확인합니다.
npm --version함께 설치된 npm 버전을 확인합니다.

버전 번호가 표시되면 Node.js와 npm이 정상적으로 설치된 것입니다.

05

npm — 필요한 패키지를 설치하고 관리

npm은 개발에 필요한 패키지(package)를 설치하고 관리하는 도구입니다. 이미 만들어진 여러 패키지를 가져와 사용할 수 있어 모든 기능을 처음부터 직접 만들 필요가 없습니다.

npm install프로젝트에 필요한 패키지를 설치합니다.
npm run dev개발 중인 Next.js 웹사이트를 내 컴퓨터에서 실행합니다.

쉽게 말하면 npm은 개발에 필요한 프로그램과 부품을 설치해주는 관리자입니다.

06

Codex — AI와 함께 코딩하기

Codex는 코딩 작업을 도와주는 AI 에이전트입니다. 프로젝트의 파일을 살펴보고 코드를 작성하거나 수정하는 작업까지 도와줄 수 있습니다.

  • “프로필 페이지를 만들어줘.”
  • “버튼을 하나 추가해줘.”
  • “이 코드에서 오류를 찾아줘.”
  • “화면을 모바일에서도 잘 보이게 수정해줘.”

Codex 설치와 실행

npm install -g @openai/codexCodex CLI를 컴퓨터 전체에서 사용할 수 있도록 설치합니다.
codex프로젝트 폴더의 터미널에서 Codex를 실행합니다.
npm
패키지 관리 도구
install
설치
-g
Global, 컴퓨터 전체에서 사용하도록 설치
@openai/codex
설치할 Codex 패키지

Codex CLI 설치·실행 내용은 공식 OpenAI 문서를 기준으로 확인했습니다.
